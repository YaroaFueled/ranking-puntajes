# Ranking de Puntajes de Videojuego

## Descripción
Programa en consola que administra el ranking de puntajes de un grupo de jugadores usando arreglos (listas) de Python.

## Objetivo
Aplicar arreglos y vectores para almacenar, consultar, modificar y procesar un conjunto de datos: acceso por índice, recorridos con ciclos, condiciones, cálculos y búsquedas.

## Lenguaje utilizado
Python 3

## Funcionalidades
- Mostrar todos los jugadores con sus puntajes e índices.
- Consultar un jugador por su posición (índice), con validación de rango.
- Calcular el promedio, el mejor y el menor puntaje.
- Contar cuántos jugadores clasifican (1000 puntos o más) y cuántos no.
- Modificar el puntaje de un jugador y mostrar el vector actualizado.
- Buscar un jugador por nombre.

## Instrucciones para ejecutar
1. Instalar Python 3 desde https://www.python.org
2. Descargar `ranking_puntajes.py` (o clonar el repositorio).
3. Abrir una terminal en la carpeta del archivo y ejecutar:
   ```
   python ranking_puntajes.py
   ```
4. Elegir una opción del menú escribiendo su número.
